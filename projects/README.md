# Projects

Projects are the primary entry point for teams. Each project owns its working knowledge, prompts, examples, evaluations, and project-specific agent capabilities.

Start information here when it is useful to one project or has not yet demonstrated broader reuse. Do not duplicate shared resources; reference entries in `knowledge/`, `skills/`, `agents/`, and `integrations/` from the project's `project.yaml`.

## Create a project

1. Copy `templates/project/` to `projects/<project-name>/`.
2. Complete `README.md`, `AGENTS.md`, and `project.yaml`.
3. Add owners and a short description.
4. Create only the subdirectories the project expects to use.
5. Add the project to this index.
