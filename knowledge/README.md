# Shared knowledge

This directory contains reviewed information useful to more than one project. It is context an agent may need, not necessarily a procedure the agent should execute.

## Categories

- `missions/`: mission objectives, products, and authoritative resources
- `sensors/`: observing characteristics, calibration, and limitations
- `datasets/`: access, schemas, provenance, quality, and licensing
- `models/`: scientific and computational model knowledge
- `algorithms/`: methods, assumptions, inputs, outputs, and limitations
- `scientific-domains/`: terminology and cross-project scientific context
- `computing-platforms/`: shared platform concepts that are not integration instructions

Use `templates/knowledge-entry/README.md` as the starting point. Keep project-specific application notes in the project directory and link to this canonical entry.
